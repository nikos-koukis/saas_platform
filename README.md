# Mini SaaS Dashboard

List, filter, search, create and edit projects — each with a status, deadline,
assigned team member and budget.

| Folder      | Stack                                            | Port |
| ----------- | ------------------------------------------------ | ---- |
| `backend/`  | Next.js API routes, MongoDB (Mongoose), JWT auth | 4000 |
| `frontend/` | Next.js App Router, Tailwind CSS                 | 3000 |

Setup and usage instructions follow in a later commit.
